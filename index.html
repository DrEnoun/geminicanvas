TRANSFORM · Guided calculation learning

Don't build a calculator. Build a tutor.

2Mg + O₂ → 2MgO

If 6.0 g Mg reacts completely with excess oxygen, what mass of MgO is formed?

Use M(Mg) = 24.3 g mol⁻¹ and M(MgO) = 40.3 g mol⁻¹.

1 · Identify the given quantity

What quantity is provided?

2 · Convert Mg mass to moles

n = m / M. Enter moles of Mg.

3 · Apply the mole ratio

From 2Mg → 2MgO, what is the Mg : MgO mole ratio?

4 · Convert moles of MgO to mass

m = n × M. Enter the expected mass of MgO.

5 · Final check

Does your answer include the correct unit and sensible magnitude?

Expected answer ≈ 9.95 g MgO. The tutor scaffolds the reasoning instead of jumping straight to the number.

Trainer Toolkit Appendix

Run it again.

Core VSEPR build prompt

Act as an educator designing a first-year chemistry microlearning activity. Create an interactive VSEPR learning experience for CH4, NH3 and H2O. Use the flow LEARN → PREDICT → EXPLORE → CHECK → FEEDBACK. Do not reveal the molecular shape until the learner commits to an answer. Give concise feedback explaining how lone pairs affect molecular geometry.

Refinement prompts

• Make the wording suitable for first-year students. • Add immediate feedback for wrong answers without revealing the answer too early. • Improve the layout for mobile screens. • Add a rotatable 3D-style molecular visual, but preserve prediction before reveal. • Check all chemistry explanations for internal consistency.

Stoichiometry transformation prompt

Keep the same microlearning philosophy, but redesign the experience as a guided mass-to-mass stoichiometry tutor using 2Mg + O2 → 2MgO. Scaffold the learner through balanced equation → given quantity → moles → mole ratio → mass → units → final answer. Give feedback at each step. Do not behave as a one-click calculator.

Peer review checklist

Accurate · Clear · Interactive · Student-friendly · Reusable

Responsible AI

Verify subject accuracy and calculations. Avoid uploading identifiable student data. Check institutional requirements before sharing or deploying AI-generated teaching materials.

Canvas beyond interactive apps

Use the same workspace for lesson-plan drafting, rubric refinement, structured notes and other teaching documents — but keep this workshop centred on interactive learning design.
