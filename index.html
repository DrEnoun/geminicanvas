STEP 05 · TRANSFORM · HANDS-ON · BUILD WITH ME

Calculation Tutor · Version 1

Keep your VSEPR prototype for comparison. Open a new Gemini Canvas and build the calculation scaffold first — not the polished app.

1Open a new CanvasDo not overwrite your VSEPR prototype.
2Paste the starter promptUse the trainer-provided Mg → MgO problem below.
3Preview before improvingCan the learner move through the reasoning one step at a time?
4Test one wrong answerCheck whether the tutor gives useful feedback instead of simply revealing the final answer.

Why no second NotebookLM setup here? This is a short transfer exercise using one fixed trainer-provided problem. For your own teaching material, you will return to NotebookLM using the Prompt Generator Wizard.

STARTER PROMPT

Build the reasoning scaffold

Create a first-year chemistry guided mass-to-mass stoichiometry tutor. Use this fixed problem: 2Mg + O₂ → 2MgO If 6.0 g Mg reacts completely with excess O₂, calculate the mass of MgO formed. Use M(Mg) = 24.3 g mol⁻¹ and M(MgO) = 40.3 g mol⁻¹. Do NOT make a one-click calculator. Guide the learner through these stages one at a time: 1. Identify the given quantity. 2. Convert mass of Mg to moles. 3. Use the Mg : MgO mole ratio. 4. Convert moles of MgO to mass. 5. Check the final unit and whether the answer is sensible. Require a learner response before moving to the next stage. Give brief formative feedback after each response. Do not reveal the final answer at the beginning.
STEP 05 · TRANSFORM · HANDS-ON · REFINE WITH ME

Now improve it one prompt at a time.

Do not replace the whole build. Send these as follow-up instructions to the same Canvas.

FOLLOW-UP 01

Scaffold, don't reveal

Improve the tutor so that each stage is locked until the learner attempts it. If an answer is wrong, give a short hint that points to the next reasoning move without immediately giving the correct number. Let the learner try again.
FOLLOW-UP 02

Make thinking visible

Show the learner's reasoning path visually as: GIVEN → MOLES Mg → MOLE RATIO → MOLES MgO → MASS MgO → CHECK. Highlight the current stage and keep completed stages visible so the learner can see how the calculation is connected.
FOLLOW-UP 03

Make it classroom-ready

Make the tutor mobile-friendly and student-friendly. Add a restart button, clear units beside numerical inputs, accessible labels, and a final explanation that reconstructs the full calculation only after the learner completes all stages. Keep the final answer approximately 9.95 g MgO using the supplied molar masses.

Test after every follow-up: correct input · wrong input · units · retry behaviour · final answer. Then compare your build with the working tutor on the next slide.

TRANSFORM · Guided calculation learning

Don't build a calculator. Build a tutor.

2Mg + O₂ → 2MgO

If 6.0 g Mg reacts completely with excess oxygen, what mass of MgO is formed?

Use M(Mg) = 24.3 g mol⁻¹ and M(MgO) = 40.3 g mol⁻¹.

1 · Identify the given quantity

What quantity is provided?

2 · Convert Mg mass to moles

n = m / M. Enter moles of Mg.

3 · Apply the mole ratio

From 2Mg → 2MgO, what is the Mg : MgO mole ratio?

4 · Convert moles of MgO to mass

m = n × M. Enter the expected mass of MgO.

5 · Final check

Does your answer include the correct unit and sensible magnitude?

Expected answer ≈ 9.95 g MgO. The tutor scaffolds the reasoning instead of jumping straight to the number.

Peer review checklist

Accurate · Clear · Interactive · Student-friendly · Reusable

Deliver to students

Core route: finished Canvas → Share & export → Share → copy public link → test on another device/account → post the link in Google Classroom, LMS, email, class group, or convert it to a QR code using an approved tool.

Trainer pre-check: test sharing with the actual institutional Workspace account before the session. Admin settings can restrict sharing. Shared Canvas content opens on gemini.google.com rather than inside the Gemini mobile app. For multi-user Canvas apps, do not collect sensitive or identifiable student data because shared app data may be visible or editable to people with the public link.

Responsible AI

Verify subject accuracy and calculations. Avoid uploading identifiable student data. Check institutional requirements before sharing or deploying AI-generated teaching materials.

Canvas beyond interactive apps

Use the same workspace for lesson-plan drafting, rubric refinement, structured notes and other teaching documents — but keep this workshop centred on interactive learning design.
